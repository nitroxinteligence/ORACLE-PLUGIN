ORACLE SYSTEM | INSTALAÇÃO LOCAL PARA MAC

O instalador completo inclui o plugin e seu runtime. Ele instala pelo
gerenciador local oficial do ChatGPT/Codex Desktop, sem enviar um arquivo
para a criação de plugins na conta. Não exige Git, Node, Python ou Xcode.

1. Extraia este ZIP.
2. Abra "Instalar Oracle.command".
3. Aguarde a confirmação com a versão instalada.
4. Abra Plugins no ChatGPT/Codex Desktop e escolha Oracle System.

Se o macOS não abrir o arquivo pelo Finder, abra Terminal, digite bash e um
espaço, arraste "Instalar Oracle.command" para a janela e pressione Enter.
Não é necessário desativar proteções do macOS nem usar sudo.

Requisitos: macOS 13+, Apple Silicon e ChatGPT/Codex Desktop
atualizado, com o comando oficial de instalação de plugins disponível.
Políticas da sua organização continuam sendo aplicadas pelo aplicativo.
Internet é necessária para a ativação da licença e para as atualizações.
Na edição pequena, sem plugin.zip, o plugin é obtido do GitHub durante a
instalação. Prefira o arquivo Mac-Instalador-Completo.zip.

Este ZIP é um instalador local. Não o selecione em "Adicionar plugin".
O ZIP normal do plugin continua disponível separadamente.

O instalador pode ser executado novamente: instala a mesma identidade local.
No pacote completo, a fonte fica em Library/Application Support fora da
pasta de Downloads e de .work. Apagar a pasta extraída não reinicia o setup.
O instalador não cria registros privados na conta, remove
outros plugins, escolhe seu vault, ativa hooks nem modifica consentimentos.
Instalações antigas importadas por ZIP permanecem sob o controle da conta.

No Oracle, confirme sua licença, escolha seu Obsidian e as permissões.
Para atualizar depois, use Atualizações dentro do Oracle. O canal verifica
as releases assinadas e compatíveis do GitHub.
