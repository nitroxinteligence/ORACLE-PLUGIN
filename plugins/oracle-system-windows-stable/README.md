# Oracle System Windows x64

Candidato privado para importação do ZIP na superfície de plugins compatível. O host inicia Bun oficial diretamente, sem comando manual. Preserva a interface Oracle e o conteúdo técnico admitido pelo distribuidor.

Importação, execução de MCP, ACL, provedores Windows e jornada completa precisam ser verificados em Windows real. AI Memory oficial depende de VCRUNTIME140.dll. Nenhuma instalação de dependência ou alteração de proteções é realizada pelo pacote.
